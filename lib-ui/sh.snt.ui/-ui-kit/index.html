UI Kit/sh.snt.ui/UiKit

UiKit

object UiKit(source)

Shared factory and typography utilities used across the desktop UI.

Fonts are loaded once from bundled resources; view helpers return fresh JavaFX nodes styled with the shared CSS classes.

FontFace
Link copied to clipboard
enum FontFace : Enum<UiKit.FontFace>

Haskoy's variable face contains a real named SemiBold instance. It is deliberately kept separate from the static Bold face: JavaFX CSS can otherwise turn every bold declaration into the same face on versions that do not resolve variable-font axes.
