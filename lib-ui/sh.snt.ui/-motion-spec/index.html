MotionSpec

object MotionSpec(source)

The shared motion contract for the two applications.

Keep the animation implementation here rather than making each screen subtly different. Axis.HORIZONTAL is used by the cashier's order-type rail and Axis.VERTICAL by the manager navigation indicator; both use the same duration, easing and interruption behavior.
