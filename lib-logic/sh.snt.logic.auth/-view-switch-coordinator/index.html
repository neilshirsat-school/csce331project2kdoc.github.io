ViewSwitchCoordinator

class ViewSwitchCoordinator(source)

JavaFX-free authorization and ownership policy for in-process destinations.

The coordinator decides whether a switch is allowed; it never creates a stage. The launcher listens for requests (see PosViewSwitchBus) and performs the actual scene replacement.

val coordinator = ViewSwitchCoordinator()
coordinator.signIn(managerUser)
check(coordinator.view == PosView.MANAGER)
check(coordinator.switchTo(PosView.CASHIER) == ViewSwitchResult.SWITCHED)
