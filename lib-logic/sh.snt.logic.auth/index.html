Business Logic/sh.snt.logic.auth

Package-level declarations

Authentication domain types and startup coordination.

  • AuthenticationResult distinguishes success, invalid credentials, and disabled accounts.

  • AuthenticatedUser exposes roles and permissions; capability helpers drive shell selection.

  • PasswordHasher implements PBKDF2-HMAC-SHA256 with per-user salts.

  • StartupHandoff passes the authenticated user from the launcher to a feature shell in the same JVM.

  • PosView / ViewSwitchResult model in-process cashier/manager switching.

object PasswordHasher

Password hashing that can run without a platform-specific native provider. PBKDF2-HMAC-SHA256 with a per-password random salt is deliberately encoded as an application-owned, versioned value. Passwords are never persisted by this class, only the one-way encoded hash.
