Business Logic/sh.snt.logic.repo

Package-level declarations

Repository contracts consumed by services. Implementations may be backed by JDBC/Exposed or by in-memory fixtures.

  • MenuRepository — available menu items.

  • OrderRepository — persist an order and return its id.

  • InventoryRepository — low-stock items.

  • CustomizationRepository — option groups for a menu item.

Keeping these as interfaces lets the cashier run against mock data while the production application uses the database module.
