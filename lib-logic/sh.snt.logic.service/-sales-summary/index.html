SalesSummary

data class SalesSummary(val netSales: BigDecimal, val orders: Int, val averageOrder: BigDecimal, val refunds: BigDecimal, val trend: List<DailySales>, val topSellers: List<SellerSales>, val itemSales: List<SellerSales> = topSellers)(source)

Aggregate sales report for a date range.

averageOrder is zero when there are no posted orders. trend contains one entry per day in the requested range, including zero-sales days, so charts have a continuous x-axis. itemSales is the full ranking while topSellers is its first five entries.
