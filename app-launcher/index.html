Launcher

The launcher is the packaged entry point for the desktop client. It installs the shared sign-in experience, probes database readiness in the background, and dispatches to the manager or cashier shell according to the authenticated user's capabilities.

Startup sequence

  1. Install DesktopChrome and show the shared sign-in scene immediately.

  2. Start a daemon thread that validates configuration and executes SELECT 1.

  3. On success, mark the sign-in surface ready and authenticate credentials through AuthRepository.

  4. Publish the user with StartupHandoff and open ManagerApp or CashierApp.

A failed connection remains a blocking sign-in error. The launcher never opens a separate settings dialog or silently falls back to demo data.
