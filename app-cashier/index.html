Cashier App

The cashier application is a JavaFX order-entry shell. It loads the menu, supports customization and cart editing, validates stock, and completes payment through the shared services and repositories.

Responsibilities

  • Display category chips and searchable menu cards.

  • Build an immutable Order through OrderService.

  • Show live ingredient availability and shortages through CartInventory.

  • Validate tender and discount input with PaymentService.

  • Persist completed sales through the database repositories.

  • Fall back to local fixture data when no database is configured.

Structure

CashierApp owns the JavaFX stage and screen state. Private helper functions build individual regions (menu grid, cart panel, checkout dialog) and are kept in the same file so the screen lifecycle is easy to follow. Reusable widgets live in lib-ui; pricing and validation rules live in lib-logic.

Threading

JavaFX mutations happen on the FX application thread. Database loads run on background executors and publish results with Platform.runLater. No blocking JDBC call is made while rendering a frame.
